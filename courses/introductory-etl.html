Introductory ETL

In Introductory ETL, I used Alteryx to prepare, transform, and combine data. The featured work below covers basic transformations, a multi-exercise assignment, and one larger case study with several supporting files.

Technical Skills

  • Alteryx Designer
  • Data cleansing and transformation
  • Joins, Union, Unique, and Text to Columns
  • Calculated fields and regular expressions

Featured Coursework

M8 Case Study – Lead Data Preparation

Used Alteryx to combine lead data with location reference information, clean and standardize fields, and prepare the records for further use. This was one case study with multiple supporting files, not four separate assignments.

Files belonging to this case study
  • chatzenb_M8.yxmd – main Alteryx workflow
  • chatzenb_M8.yxzp – packaged workflow containing its supporting inputs
  • PackExpo23.xlsx – source lead data
  • states(1).xlsx – location reference data

The original packaged project also contains a reference to chatzenb_M5.xlsx. Source workbooks are not linked publicly because the lead file includes contact information.
