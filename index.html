Intro to Computers & Programming

This course introduced me to the fundamentals of computer systems and programming. I developed an understanding of programming logic, problem-solving, and how to approach technical challenges using structured solutions.

Programming Fundamentals

This course expanded my understanding of programming through JavaScript. I gained experience working with variables, conditional statements, loops, and functions while developing my problem-solving and debugging skills. I also learned how to organize code and break larger programming tasks into smaller, more manageable steps.

Featured Coursework

  • Pseudocode Development: Improved my ability to write detailed pseudocode to outline program logic, organize ideas, and plan solutions before beginning the coding process.
  • AI in Software Development: Researched how AI-assisted programming can affect developers' understanding of their own code. Examined the potential drawbacks of relying on AI while recognizing its growing role in software development.
  • JavaScript Final Project: Developed an interactive Dungeons & Dragons character creator using HTML, CSS, and JavaScript. Implemented character customization, randomized ability scores, racial bonuses, and dynamic character previews using functions, conditional statements, loops, and user input.

Python Data Programming

This course focused on using Python to work with and analyze data. I gained experience importing datasets, cleaning and transforming information, and using libraries such as pandas to manipulate and explore data. I also developed my ability to write Python scripts that automate data processing tasks and prepare information for analysis and reporting.

Featured Coursework

  • Baseball Team Manager: Expanded a Python application that uses SQLite to manage a baseball team's roster and lineup. Implemented functionality to add, remove, reorder, and edit players while managing batting statistics and storing information in a database.
  • Python Task Manager: Developed a task management application using Python and SQLite, incorporating user authentication, task creation, categories, and basic search functionality. Organized the application into multiple Python modules to manage database operations, object classes, and user interactions.

Machine Learning

This course introduced me to machine learning and how predictive models can be developed using data. I gained hands-on experience using Python and scikit-learn to build linear and logistic regression models. I also learned how to prepare training and testing datasets, evaluate model performance, and identify ways to improve predictions through data preparation and adjustments to the model.

Featured Coursework

  • Linear Regression: Used Python and scikit-learn to develop a regression model that predicts vehicle prices based on characteristics such as horsepower, engine size, and vehicle dimensions.
  • Logistic Regression: Developed a classification model using the Titanic dataset to predict passenger survival based on age and sex. Practiced splitting data into training and testing sets and evaluating model predictions.
  • Image Classification: Used Google's Teachable Machine to train an image recognition model. Improved its ability to distinguish objects by adding training images with different backgrounds and examining classification errors.
